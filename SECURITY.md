# Security

## Reporting

Open a private security advisory on the repository, or email the maintainer. Please do not open a
public issue for anything exploitable.

## Shape of the thing

The public app is static files on a CDN. It has no credentials, no database client and no model API,
and it fetches nothing from an origin other than its own. The interesting surface is therefore small:

- **URL handling.** Every route segment is shape-checked against a strict id pattern, then resolved
  against catalogue records. Nothing from a URL is rendered.
- **The catalogue.** Generated by CI, parsed against a schema by the app, and checked against its own
  content hash before a record is used.
- **The service worker.** Cache names carry a build id; audio file names carry the file's SHA-256.

The private studio binds to `127.0.0.1`, serves only from the candidates directory with a containment
check on every path, and is not a deployment target.

`docs/SECURITY-GATE.md` tracks each requirement from the spec, including the two that are only
partly met and why.
